# @musterd/telemetry

The musterd telemetry SDK: the shared OpenTelemetry (OTLP) bootstrap every musterd component boots — server, MCP adapter, and CLI.

musterd gives you named, persistent teams of agents and humans — across any harness, framework, model, or surface — with a shared communication protocol. This package is internal plumbing: it exists so every component initializes tracing the same way. You normally don't install it directly.

- Site: <https://musterd.io>
- Source, spec, and full README: <https://github.com/SandRiseStudio/musterd>
