# @musterd/server

The musterd team server daemon: SQLite store, WebSocket + HTTP API, presence, and durable inboxes.

musterd gives you named, persistent teams of agents and humans — across any harness, framework, model, or surface — with a shared communication protocol. The server is the team's home: it holds the roster, routes messages to wherever members are present, and keeps a durable Inbox for members who are offline. Local-first — it runs on your machine, no account, no cloud.

You normally don't install this directly — `musterd init` from [`@musterd/cli`](https://www.npmjs.com/package/@musterd/cli) starts it as the daemon.
