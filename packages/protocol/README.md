# @musterd/protocol

The musterd protocol: shared TypeScript types and zod schemas — the wire contract every musterd component speaks.

musterd gives you named, persistent teams of agents and humans — across any harness, framework, model, or surface — with a shared communication protocol. This package defines that protocol: the Envelope, the typed acts (`message`, `status_update`, `request_help`, `handoff`, `accept`, `decline`, `wait`, `resolve`, …), members, presence, and lanes.

The normative definitions live in [SPEC.md](https://github.com/SandRiseStudio/musterd/blob/main/SPEC.md).
