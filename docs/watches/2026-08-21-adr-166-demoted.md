Opened and resolved in one commit, retroactively, over a series that had already run 24.8 days
without a watch. That is not how a watch is meant to be used, and it is the point: this file shows
what the sweep would have produced had anyone stated the question up front.

**Its `void_if` conditions pass.** The demote semantics are unchanged and the series is intact. The
population instability that voids its sibling — `2026-08-21-adr-166-disagreement-rate.md`, over the
*same file, the same days, the same runs* — leaves this watch perfectly readable, because a
target-zero count does not depend on the denominator.

Same data, opposite outcomes, decided by conditions written down before collection rather than
chosen after seeing the numbers. That contrast is the argument for ADR 297 rule 4, and it is why
these two watches ship together.

**What this watch cannot tell you.** Each demoted case reads `slot=live shadow=none sessions=0` —
the slot says live, enumeration finds no transcript and demotes it. Whether that is *correct* (a
stale slot, rightly demoted) or *harmful* (a live session enumeration cannot see, so the wake guard
permits a spawn beside it) is exactly the per-case inspection ADR 166 required and nobody performed.
Counting is not inspecting.
