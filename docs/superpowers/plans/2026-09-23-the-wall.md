# The wall (lane 1 of reach & boundaries) — implementation plan

> **For agentic workers:** implement this plan task-by-task in your own seat
> (`superpowers:executing-plans`). Do **not** dispatch writing subagents — AGENTS.md hard rule 8.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A seat can no longer reach, read, or message any harness session outside its own team's
seat set. It can no longer act as any member other than its Workspace's binding. The seat↔seat
relay is gone.

**Architecture:** Four cuts ship as one increment:
1. The daemon stops issuing `delivery_hint`, and the relay skill is deleted.
2. The PreToolUse gate refuses session-reaching tools **locally**, before any daemon round trip,
   and audits each refusal.
3. The CLI resolves identity from the Workspace binding (or `MUSTERD_*` env) only. `--as` and the
   global-config fallback are removed.
4. Every line names its team and is worded as a pointer.

**Tech stack:** TypeScript, zod (`@musterd/protocol`), better-sqlite3 audit (`@musterd/server`), the
`musterd gate check` hook one-shot (`@musterd/cli`), vitest.

**Spec:** `docs/superpowers/specs/2026-09-23-reach-and-boundaries-design.md` — §2, §3, §4, §6 (the
lane 1 part), §7. Lanes 2–5 of spec §9 get their own plans.

## Global constraints

- `pnpm` is `/Users/nick/Library/pnpm/pnpm` on this laptop (not on the harness PATH).
- **Protocol changes are ADR-gated** (AGENTS.md rule 1). Task 0's ADR covers every protocol change
  here. Commit footer on each commit: `Refs ADR-<N>`.
- Docs and code never disagree at the end of a commit (rule 3). Each task updates its own docs.
- New source files need a described line in their package's `docs/architecture` file tree
  (`arch-trees:check`).
- Never log secrets (rule 5). Audit rows carry the tool name and harness only — no body, no target,
  no session id.
- A gate must never break an unrelated tool call: the existing fail-open posture (`gateCheck`'s
  `catch`) stays for enforcement classes. **The session-reach deny is decided before anything that
  can throw**, so a daemon outage cannot open it.
- §7 honesty: every doc this lane touches states that the wall stops model mistakes. It does not
  stop a hostile same-user process.
- Fast gates before every push: `pnpm typecheck && pnpm lint && pnpm format:check`.

## Review focus

1. **A seat's own subagents** — `SendMessage` to a subagent the session spawned must still work.
   Expect: allowed. Pinned in Task 4.
2. **Unbound folder, human in the vault** — `musterd inbox` from a folder with no binding, on a
   machine whose `~/.musterd/config.json` holds nick. Expect: "no identity in this folder", exit 4,
   and no read as nick. Pinned in Task 6.
3. **Subfolder and symlink of a seat Workspace** — the gate and the resolver treat both as the seat.
   A symlink out of a Workspace does not carry its binding. Pinned in Task 6.
4. **Daemon down** — the session-reach deny still fires. Only the audit row is lost. Pinned in
   Task 4.
5. **Old adapter against the new daemon** — an ack with no `delivery_hint` must not break
   `team_send` in an adapter built before this lane. The field was always optional, so expect no
   change. Pinned in Task 2.

/** ADR <N> — every harness tool that discovers, reads or messages another harness session. The gate
 *  refuses these in a seat Workspace. `SendMessage` is also a session's channel to its OWN subagents,
 *  so the gate scopes it (SUBAGENT_CHANNEL_TOOLS); every other entry is refused outright. An unknown
 *  session-reaching tool is a gap to add here, not a pass. */
export const SESSION_REACH_TOOLS: readonly string[] = Object.freeze([
  CCD_SEND_MESSAGE_TOOL,
  'mcp__ccd_session_mgmt__list_sessions',
  'mcp__ccd_session_mgmt__list_events',
  'mcp__ccd_session_mgmt__search_session_transcripts',
  'mcp__ccd_session_mgmt__get_session',
  'ListAgents',
  'SendMessage',
]);
export const SUBAGENT_CHANNEL_TOOLS = ['SendMessage'] as const;
export function isSessionReachTool(tool: string): boolean {
  return SESSION_REACH_TOOLS.includes(tool);
}
