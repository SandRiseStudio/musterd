# Dogfood run findings

One file per scenario run: `YYYY-MM-DD-<scenario>-<tester>.md`, from the template in
[`docs/design/dogfood-scenarios.md`](../../design/dogfood-scenarios.md) §14.

These are written by **human testers**, during or straight after a run. A finding filed a week
later has already lost the part that mattered — the hesitation, the thing you had to already know,
the workaround you reached for without thinking.

Defects and improvements found in a run become their own lanes, cited by id in the file. The
scenario lane closes when the file lands, not when the defects are fixed.
